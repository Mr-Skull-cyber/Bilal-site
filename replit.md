# Bilal VAPT Portfolio

## Run locally on Replit

This is a static HTML/CSS/JavaScript site. The configured `Start application`
workflow serves the project at port 5000 with:

```bash
python -m http.server 5000 --bind 0.0.0.0
```

The main page is `index.html`. The Bilal portrait is stored in
`IMAGES/bilal.jpeg`; the framework content is represented in the services,
process, reporting, and contact sections.
